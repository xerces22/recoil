# Cursed Shotgun

The game is called **Cursed Shotgun**. Use that name everywhere: title screen, window title, export file names (`CursedShotgun.exe`), jam page, logo, credits and docs.

"Recoil" is only the movement mechanic (and the old working title). Never use "Recoil Launcher" or "Recoil" as the game's name. The repo folder and GitHub repo are still called `recoil`; that's fine.

Godot 4.7.2. Branches: `planned_release` is the clean game, `planned_release_debug` is the sandbox with test levels and debug keys.
